Fixed an isopleth family holding on to label artists it no longer draws
(:issue:`54`): :class:`~tephpy.plotting.isopleths.IsoplethFamily` pools one
:class:`~matplotlib.text.Text` per inline label and grew that pool to fit each
draw, but never gave the surplus back. Anything that shrinks the labelled set —
zooming back out after a finer ladder step, or claiming an edge, which hands
the members reaching it to the axis ticks — left the high-water mark pinned for
the life of the axes; a round trip through the default view's zoom ladder
retained 40 labels that would never be drawn again. The pool is now trimmed to
what each draw actually labels. (:user:`claude`)
