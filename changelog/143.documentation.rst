Added an experimental browser tutorial that lazily runs the current tephpy wheel
entirely client-side, plots its bundled sounding on an interactive matplotlib
canvas, accepts local CSV uploads, and exposes normalized plotted values in a
collapsible table. The tutorial also explains each navigation control with its
Matplotlib icon, and the demo anchors those controls to the left so the live
cursor readout, anchored to the right, cannot move them. Focusing the plot on
the first pointer press also preserves the page and iframe scroll positions.
(:user:`openai`)
