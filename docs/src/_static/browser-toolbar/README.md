# Matplotlib Toolbar Icons

These unmodified SVG files are the source artwork corresponding to the toolbar
PNGs used by the browser demo's pinned Matplotlib 3.10.8 Pyodide backend:

- `home.svg`
- `back.svg`
- `forward.svg`
- `move.svg`
- `zoom_to_rect.svg`
- `filesave.svg`

They were extracted from
`matplotlib-3.10.8-cp314-cp314-pyemscripten_2026_0_wasm32.whl`, published with
Pyodide 314.0.4. The wheel SHA-256 is
`2867b2003ee66d0d2478423f783ec035d432c6560ae86d0e58d096ff98cab6a8`.

their hashes to the browser runtime versions.
